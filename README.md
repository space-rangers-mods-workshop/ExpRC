# 🚀 ExpRC

* **Name:** ExpRC
* **Author:** Huk, Klaxons, ringill
* **License:** Creative Commons BY-NC-SA 4.0

### Summary

Expands the capabilities of Ranger Centers
(The mod can be enabled/disabled during a game)

---

## 📖 Description

Expanding the functionality of ranger centers:
- The player gets a personal micromodule storage, reachable at any Ranger Center
- New Year's gift micromodules are moved into that storage automatically
- If every Ranger Center is destroyed, access to the storage is lost together with everything hidden in it
- The rate at which physical nodes are handed in for the node account is tripled
- For add-on mods that issue micromodules, the Ranger Center network now has limited reserves
- All the questions about rangers, nodes and pirates at a Ranger Center were moved into a separate dialogue
<clr><clrEnd>
New game mechanics:
- The player can collect unknown micromodules that occasionally drop from dominators
- Unknown micromodules are handed in at a Ranger Center for a substantial reward, and every 25 of them earn the player a special experimental micromodule
